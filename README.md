# Sales Data Analysis System using Python and JSON
## Project Overview
This project analyzes sales order data stored in a JSON file using Python. It helps summarize customer orders, sales revenue, product quantities, and customer spending.
## Features
• Load sales data from a JSON file.
• Count total orders and unique customers.
• Calculate revenue based on order status.
• Calculate completed sales revenue by category.
• Find product-wise quantities sold.
• Calculate completed spending for each customer.
• Identify the highest-spending customer.
• Identify the highest-revenue category.
• Find the most-sold product.
• Classify customers based on their spending.
